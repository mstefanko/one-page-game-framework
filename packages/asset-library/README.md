# @onepage/asset-library

IndexedDB drafts with atomic revision checks, immutable saved versions, recoverable deletion, validated library backup/restore, storage capability helpers and separate demo-project assignments.

Implemented browser adapter. No cloud, filesystem picker integration, or mutable runtime dependency on the personal library.

See the [current implementation plan](../../docs/06-pocket-score-implementation.md) and [validation limits](../../docs/08-implementation-validation.md). These workspaces remain private source packages, not published npm releases.
