# @onepage/music-web-audio

Shared native-node synth and audio-clock scheduler, distinct deterministic drums, intensity switching, offline PCM rendering and PCM16 WAV encoding. Editor and exported player share this code.

Implemented baseline; sound/device qualification and comparative listening remain open. See [backend proof](../../docs/07-backend-proof.md).

See the [current implementation plan](../../docs/06-pocket-score-implementation.md) and [validation limits](../../docs/08-implementation-validation.md). These workspaces remain private source packages, not published npm releases.
